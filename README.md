# MAK Dental V2.0

Statik HTML, CSS ve vanilla JavaScript ile hazırlanan yerel tasarım demosu. `index.html` bir HTTP sunucusundan, tek dizin altında veya `/mak-dental/` önekiyle açılabilir. SVG simgeler ve Manrope WOFF2 dosyaları yereldir. Font lisansı `assets/fonts/` içindedir.

Planlanan GitHub Pages kaynağı `bartsscreative/mak-dental`, planlanan adres `https://bartsscreative.github.io/mak-dental/`. ZIP kökündeki **.nojekyll**, HTML ve varlıkları birlikte koruyun. Open Graph görsel URL’si planlanan adresi kullanır.

Kullanıcının 25 Kasım 2026 tarihli yayın teyitleri için [firma teyit listesine](FIRMA_TEYIT_LISTESI.md) bakın.
